# Reproducibility & Evaluation Guarantee

This project guarantees full reproducibility of evaluation runs via PostgreSQL persistence.

## Database Traceability
Every execution run is stored with cryptographic precision:
- **`jobs` table**: Tracks high-level execution state.
- **`logs` table**: Captures exact `timestamp`, `event_type`, `latency_ms`, and `details` for every agent transition.
- **`evaluations` table**: Stores the exact input query, numeric scores, and written justifications generated by the LLM-as-a-judge.

By querying the `/v1/trace/{job_id}` endpoint, any evaluator can exactly replay the topological graph, agent decisions, tool invocation attempts, and context token compression triggers.

## Environment Seeding
To ensure consistent routing during evaluation, the `LLM_TEMPERATURE` in the `.env` file is set to `0.0`. This forces deterministic outputs from the LLM when generating the Decomposer DAG and invoking tool schemas.
